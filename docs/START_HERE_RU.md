# MoneyPilot: с чего начать
Manyakina Yuliya и Bazarbayev Bakdaulet, SE-2509.

1. Распакуйте архив целиком. Нужна Java 17 или новее. Запускайте run.bat. Если Java не найдена, установите JDK 17+ и откройте терминал заново.
2. Для репетиции запускайте: java -jar MoneyPilot.jar demo-data.properties. Это отдельный файл данных рядом с проектом.
3. Выберите 2026-11 и нажмите Apply. Нажмите Load demo один раз. Получатся доходы 180000, расходы 80000, monthly net 100000 KZT.
4. Прочитайте свой отдельный гайд. Потом пройдите общий сценарий с секундомером.
5. Не загружайте демо повторно без Undo: кнопка добавляет записи, а не заменяет базу.

## Что сдавать
В Moodle: MoneyPilot_Report.pdf и MoneyPilot_Project.zip. Презентация отдельно: MoneyPilot_Presentation.pptx. Личные гайды и текст речи нужны для подготовки.

## Что открыть заранее
Приложение, презентацию и IDE с классами Transaction, EventBus, LegacyBankAdapter, MoneyPilotFacade, TransactionCommand, CommandHistory, BudgetStrategy. В приложении должны быть видны все категории, поиск пустой. Держите samples/bank-demo.csv под рукой.

## Важные ограничения
Monthly net показывает доходы минус расходы выбранного месяца. Это не баланс банковской карты. Все суммы в KZT. Реальной связи с банком нет. Лимит бюджета общий для всех месяцев. Undo работает для операций в текущем запуске, настройки не отменяет. Два экземпляра приложения не должны одновременно менять один файл.
